# Glossary (weimeijiao)

The terminology reference for all three locales (SPEC §6). Writers and reviewers use these terms exactly; the content lint (`scripts/check-content.mjs`) rejects the banned forms listed at the end. Simplified Chinese follows mainland usage, Traditional Chinese follows Taiwan usage (vocabulary, not only character forms), English is US English. Add a row when a new term enters the site; never rename a term in one locale only.
